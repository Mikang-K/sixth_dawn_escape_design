# 3층 서쪽 — 답장이 없는 무인 우편 교환국

분류, 실제 인도, 수신 확인이 서로 다른 상태임을 배우는 방. 실제 통신 표준을 알아야 하는 문제로 만들지 않는다. 화면에 적힌 수동 전달 규약만으로 모두 해결한다.

## R5-1 — 지워진 네 주소

- 목표·진입: 봉투 P/Q/R/S를 북 N·동 E·남 S·서 W의 분류함에 하나씩 넣는다. R3-3과 R4-3 이후. 난도 3/5, 7~9분 예상.
- 초기 상태: 같은 주소로 두 봉투를 보낼 수 없다. 봉투 식별자 S와 남쪽 S는 혼동될 수 있으므로 실제 화면은 봉투 P/Q/R/S 대신 원·잎·별·물결 표식과 ‘봉투’ 접두어를 사용한다. 아래 영문은 기획 식별자다.
- 필수 단서: 분류판에 시계방향 N→E→S→W의 고리. ‘P는 Q에서 시계방향 한 칸이다.’ ‘R은 P의 정반대다.’ ‘S는 북 또는 동이다.’ ‘Q는 서가 아니다.’
- 조작 범위: 네 봉투를 각 한 번씩 네 분류함에 배치한다. 시계방향 화살표를 직접 따라볼 수 있다.
- 풀이: Q를 북·동·남 중 하나로 가정한다. Q북이면 P동/R서로 S남만 남아 불가. Q동이면 P남/R북으로 S서만 남아 불가. Q남이면 P서/R동/S북으로 모든 조건을 만족한다.
- 정답·판정: P서 / Q남 / R동 / S북, 24개 대응 중 1개. ‘정반대’는 고리 두 칸이라는 그림도 제공한다.
- 오답 피드백: 고리 위에 위반한 관계선을 표시한다. 봉투를 배달해 소모하지 않고 분류함에서 다시 꺼낸다.
- 힌트 1: ‘주소 이름을 외우지 말고 고리에서 관계를 보자.’ 2: ‘Q를 북에 놓을 때와 동에 놓을 때 S가 갈 수 있는지 확인한다.’ 3: ‘원/P 서, 잎/Q 남, 별/R 동, 물결/S 북.’
- 복구·보상: 수신 처리대 R5-2가 열린다. 봉투 속 사전 접수증에서 ‘폐관 인계 접수: 윤서’를 확인한다. 이 사실은 탈출 정답으로 입력하지 않는다.

## R5-2 — 이미 도착한 편지

- 목표·진입: 41번과 42번을 각각 한 번만 인도하고 두 수신 확인을 마친다. R5-1 이후. 난도 4/5, 8~12분 예상.
- 초기 상태: 41번 편지는 이미 수신기에 도착해 한 번 인도됐지만, 응답이 유실되어 송신기는 다음 번호를 여전히 41로 표시한다. 수신기 마지막 번호는 41. 확인 응답 보관칸은 비어 있다. 이 과정을 첫 화면의 짧은 기록으로 보여 준다.
- 필수 단서: ‘같은 번호를 다시 받으면 다시 인도하지 않고 그 번호의 확인만 돌려준다.’ ‘송신기는 자기 다음 번호와 같은 확인을 받아야 한 칸 나아간다.’ ‘현재 확인칸에 없는 번호를 확인할 수 없다.’ 전송은 즉시 도착하며 새 시간 지연이나 무작위 손실은 발생하지 않는다.
- 조작 범위: 네 작업 카드 R41 ‘41 재전송’, A41 ‘41 확인 수령’, S42 ‘42 새 전송’, A42 ‘42 확인 수령’을 각 한 번 사용해 순서를 정한다. 번호·상태를 보며 한 단계씩 실행한다.
- 풀이: 확인칸이 비었으므로 A41부터 할 수 없다. R41이 중복을 재인도하지 않고 확인41을 만든다. A41 후 송신 다음 번호가 42로 바뀌어 S42가 가능하다. 그 뒤 A42로 마친다.
- 정답·판정: R41→A41→S42→A42. 24개 최소 작업 배열 중 1개. 종료는 송신 다음43, 수신 마지막42, 인도장 [41,42], 미확인 없음. 실제 반복 재전송을 허용하는 구현에서는 동일 번호의 중복 인도를 하지 않는 동치 경로도 허용해야 한다.
- 오답 피드백: A41 먼저는 ‘41 확인이 아직 응답칸에 없다’. S42 먼저는 ‘송신기가 아직 41의 확인을 기다린다’. 잘못된 카드는 거부하고 실행된 정상 단계는 유지한다.
- 힌트 1: ‘보내는 쪽과 받는 쪽이 서로 다른 번호를 보고 있다.’ 2: ‘다시 보내도 두 번 인도하지 않는다는 규약을 이용한다.’ 3: ‘41 재전송 → 41 확인 수령 → 42 새 전송 → 42 확인 수령.’
- 복구·보상: 실제 처리장과 단순 수신 기록이 다른 색·무늬의 도장으로 분리되어 수첩에 남는다. 경로 선택 장치 R5-3과 우표함 O-5가 열린다. 초기화 시 시작의 ‘41 한 번 인도, 확인 유실’ 상태를 정확히 복원한다.

## R5-3 — 일곱 박자 안에 닿는 길

- 목표·진입: 윤서의 최종 접수 봉투를 출구 기관 T에 7박자 이내로 보낸다. R5-2 이후. 난도 3/5, 6~8분 예상.
- 초기 상태: 아래 표의 단방향 운송망. 구간 비용은 이동 박자이며 장치 모의 운행으로 한 번에 계산한다. 통과한 간선을 거꾸로 타거나 도중 봉투를 나누는 조작은 없다.

| 출발→도착 | 박자 |
|---|---:|
| S→A | 2 |
| S→B | 1 |
| A→C | 2 |
| A→T | 7 |
| B→C | 4 |
| B→T | 9 |
| C→T | 3 |

- 필수 단서: ‘총 운송 박자가 7 이하여야 다음 교환창이 열린다.’ 방향 화살표와 구간 수를 지도에 함께 쓴다. 가장 싼 첫 구간이 전체 최단 경로를 보장하지 않는 배치다.
- 조작 범위: S에서 T까지 이어지는 경로를 클릭해 계획하고 시험 운행한다. ‘즉시 재생’과 구간별 재생을 모두 제공한다. 실제 시간 압박은 없다.
- 풀이: S-A-C-T는 2+2+3=7. S-A-T는 9, S-B-C-T는 8, S-B-T는 10. 처음 1박자 구간을 골라도 전체는 더 늦다.
- 정답·판정: S→A→C→T, 총7. 가능한 네 경로 중 시간 조건을 충족하는 것은 하나다.
- 오답 피드백: 예측 합계와 실제 구간 도착 기록을 보여 준다. 기한 초과는 교육용 모의 운행으로 처리하고 봉투는 회수한다.
- 힌트 1: ‘첫 갈림길만 싸게 고르지 말자.’ 2: ‘A에서 바로 T로 가지 않고 C를 거치면 얼마나 걸리는가?’ 3: ‘S → A → C → T, 2+2+3=7.’
- 복구·보상: 규칙판 **번호와 확인** 획득. 수첩은 ‘보였던 기록 전부가 처리된 일은 아니다 / 같은 번호는 한 번만’이라고 요약한다. 윤서의 접수 봉투가 출구 기관의 전용 슬롯에 보관된다. 별도 인벤토리 물품으로 잃어버릴 수 없게 한다.
