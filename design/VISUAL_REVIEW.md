# 도트 그래픽 고도화 v1.1

작업일: 2026-11-03. 기존 남색·황동·종이의 아트 계약을 이어간 시각 개선이다. 방 구성·퍼즐 규칙·진행·저장 형식은 유지했다. 표현 원본은 이 프로젝트에서 작성한 Canvas 코드이며 원본 화면은640×360이다.

**[변경 전·후 비교 갤러리](../game/qa/art-review.html)** 에서 공간과 복구 상태를 바꾸어 비교할 수 있다. 갤러리는 파일로 열어도 동작하며 이미지 폴더와 함께 보관한다.

## 무엇을 바꿨는가

| 공간·부분 | 표현 개선 | 확인할 플레이 효과 |
|---|---|---|
| 접수대 | 창밖 항구·달·비, 난방관, 작업등, 서류·잉크·책, 깔개와 캐릭터 | 첫 전원 장치와 내부 문을 가리지 않음 |
| 회랑 | 황동 아치, 방별 문양, 체인·손잡이·획득판, 연결 동선 | 개방·잠김·복구를 서로 다르게 표현 |
| 기록보관소 | 서랍의 깊이·금속 손잡이·문서 라벨, 책과 봉인 서류, 원본판 | 점검창과 복구된 서랍이 식별됨 |
| 침수 온실 | 유리 골조·빗방울·잎맥·화분, 계량통과 밸브, 수면 반사 | 배수와 개화가 실제 해결 이후에만 반영됨 |
| 야간 천문대 | 돔의 깊이·달빛·별, 경통·삼각대·렌즈, 황동 관측판 | 광선 연결과 두 관측창의 상태가 읽힘 |
| 종이 인형극장 | 커튼 주름·금색 테두리·발판, 동물별 인형 윤곽·앞뒤 위치, 줄과 스풀 | 정렬된 열쇠와 커튼콜 결과가 구별됨 |
| 우편 교환국 | 분류함·봉투 접힘·봉인, 우편관·수신기·롤러, 실제 번호 표시 | 수신 확인과 운송 완료를 서로 다른 물체로 표현 |
| 시계 공방 | 기어 톱니·스포크·표면 명암, 세 주기 바늘, 스위치·검사등 | 주기 해결과 동력 분리가 단계별로 표시됨 |
| 출구와 아침 | 실린더 수위·광학판·후퇴하는 잠금핀, 열린 문과 항구 빛, 보존/반환 소품 | 세 모듈과 두 결말의 결과가 다르게 보임 |
| 공통 UI | 조사 표식의 모서리, 패널의 재질·음각, 원본 도형의 픽셀 윤곽, 접수 도장 폭 | 기존 글자와 키보드 포커스를 유지하면서 공간과 어울림 |

재질은 단순한 밝은 잡티로 표현하지 않는다. 목재는 수평 결·접합부, 금속은 밝은 윗면·어두운 옆면·나사, 유리는 테두리와 반사, 천은 주름과 장식, 물은 수위·반사·물결로 구분했다. 밝은 무작위 흔적은 초기 개선안보다 줄였다.

## 비교 방법과 근거

- 변경 전에 [기준 이미지20개](../game/qa/art-before/manifest.json)를 저장했다. 접수대·회랑·테마6방·출구의 복구 전후18개와 두 엔딩이다.
- 같은 상태·같은 프레임에서 [변경 후20개](../game/qa/art-after/manifest.json)를 다시 그렸다.20개 모두 이미지가 바뀌었다. 이는 변경 확인이며 자동으로 미적 우수성을 증명하는 점수는 아니다.
- 원본 Canvas는640×360이다. 브라우저 요소 경계의 반올림을 포함한 비교 PNG는640×361이며 전후가 동일하다. 화면을 임의로 늘리거나 다른 진행 상태를 비교 기준으로 쓰지 않았다.
- 갤러리에서20개 항목을 실제로 선택하고, 전후 이미지의 로드와 크기 일치를 확인한다. 결과는 변경 후 manifest의 galleryValidation에 기록한다.
- 고정 상태는 미술 확인용이다. 실제29개 퍼즐 입력과 엔딩·저장·재시작의 증거는 별도의 [전체 검증 JSON](../game/qa/verification.json)을 따른다.
- 정상 진행 중의 방별 실제 UI는 전체 검증의 actual-room-art 진단에 연결되어 있다. 각 방에 실제로 진입하고 장치를 해결한 뒤 캡처했다.

## 검증과 남은 범위

판정43개에 도트 래스터·상태 불변·동일 프레임 재현·두 엔딩 구분 검사4개를 더한47개 검사를 수행했다. 브라우저에서는 전체 경로와 키보드·저장 경로를 다시 확인하고, 움직임을 켰을 때 실제 픽셀 변화와 저동작에서 정지 상태를 유지하는지 확인했다. 최종 결과와 실행 빌드는 전체 검증 JSON이 기준이다.

미술 검토 도구는 장면당7회 드로우의 원시 시간을 기록한다. 이 값은 제한된 환경에서의 짧은 관찰이며 장시간 성능·여러 기기에서의 프레임률을 보장하지 않는다.

최종 판매용 아트 판정, 독립된 사람의 선호 평가, 초심자의 가독성·발견 가능성·재미, 실제 스크린리더와 다른 브라우저는 이번 시각 개선의 확인 범위에 포함하지 않았다.
