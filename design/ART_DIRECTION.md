# ART_DIRECTION — 젖은 종이와 얇은 동선

입력: [게임 기획서](GAME_DESIGN.md), [요구사항](../PRODUCT_BRIEF.md). 적용: `game-art-direction`. `targetFinish: graybox`, `experienceProfile: system-led`. 이 문서는 도트 화면의 제작 방향이다. 후속 구현의 직접 그린 도트 화면과 관찰 근거는 [게임 검증](../game/qa/verification.json)에 연결된다. 최종 원화나 미술 품질 판정은 아니다.

## 1. 한눈에 구별되는 정체성

**황동 모서리의 전사 수첩, 젖은 남색 공간, 작동할 때만 이어지는 호박색 동선.** 서로 다른 여섯 방에서도 이 세 가지는 반복한다. 종이의 닳음은 분위기이고, 빈칸·선·홈은 실제 추론 정보다. 둘을 같은 시각 강도로 그리지 않는다.

| 원칙 | 맞는 방향 | 버릴 방향 |
|---|---|---|
| 읽히는 도트 | 단서의 외곽이 명확하고 확대면에서 끊어지지 않음 | 한 픽셀의 장식 차이로 답을 가림 |
| 아날로그 장치 | 종이·황동·유리·도료와 물리적 조작부 | 여섯 방 전체를 같은 홀로그램 화면으로 통일 |
| 정적인 긴장 | 상태 변화 때만 짧은 움직임·소리 | 상시 점멸과 흔들림으로 필수 정보를 덮음 |
| 원인을 보여 주는 피드백 | 바뀐 레버에서 수신기까지 경로가 이어짐 | 성공 글자만 띄우고 부품은 그대로 |
| 비주얼의 정직성 | 실제 판정이 성공한 뒤 핀이 올라감 | 진행 전에 빛·음향으로 성공을 암시 |

시대는 특정 실재 연도로 고정하지 않은 아날로그 근대다. 매체는 윤곽이 읽히는 2D 도트. 인물은 과장된 귀여움보다 작은 작업복 실루엣으로 표현한다. 공포의 강도를 높이기 위해 신체 훼손이나 실재 재난 이미지를 추가하지 않는다.

## 2. 화면과 카메라

PC 가로 화면, 기본 창 1280×720을 기획 기준으로 둔다. 공간 구성은 640×360의 가상 좌표로 설계하고 정수 배율 확대를 지향한다. 장치 확대면에서는 한글과 수치를 최종 출력 크기에서 읽히게 별도로 배치한다. 도트풍을 지키려고 한글까지 지나치게 작은 비트맵 글꼴로 만들지 않는다.

방 전체는 단면을 보는 고정 시점이다. 문·주요 장치·회랑 복귀 지점을 동시에 확인한다. 배우의 자유 보행이나 카메라 회전이 퍼즐을 가리지 않는다. 극장의 시점 다이얼은 **투영창 안의 모형**을 바꾸고, 게임 전체 카메라는 흔들리지 않는다.

```text
┌────────────────────────────────────────────────────┐
│ 방 이름 / 현재 목표                 수첩 · 설정    │
│                                                    │
│ [단서 관찰]       [현재 장치 / 상태 변화]           │
│                                                    │
│ 문 / 회랑 ←        인물·환경          다음 장치     │
├────────────────────────────────────────────────────┤
│ 선택 물품 / 핀 단서          되돌림 · 초기화 · 힌트 │
└────────────────────────────────────────────────────┘
```

확대면은 장치, 판정 조건, 현재 상태, 실험 버튼의 네 영역을 갖는다. 수첩 비교창은 장치의 조작 영역을 가리지 않는 옆 패널이다. 격자와 레일은 한 눈금씩 스냅되어 미세한 마우스 이동이 정답을 좌우하지 않는다. 좁은 창에서는 가독성을 유지할 수 있는 최소 크기를 안내하며, 실제 대응 범위는 회색상자에서 정한다.

## 3. 색·재료·윤곽

아래 값은 팔레트 제안이며 실제 시안에서 명도 대비를 측정하고 조정한다. 색각 다양성을 색조만으로 해결했다고 주장하지 않는다.

| 역할 | 색 제안 | 색 이외의 표식 |
|---|---|---|
| 깊은 배경 | 남색 `#182331` | 큰 덩어리, 낮은 세부 밀도 |
| 읽는 종이 | 상아색 `#E9DCC1` | 밝은 면·명확한 테두리 |
| 조작할 황동 | 황동색 `#B78948` | 손잡이·나사·홈 형태 |
| 확정된 작동 | 호박색 `#F0B45C` | 닫힌 연결선·체크 홈·작동 글자 |
| 현재 관찰 | 청록색 `#74C5BA` | 점선 외곽·커서 기호 |
| 불일치 | 적갈색 `#BA665B` | 사선·불일치 문구·경로 끊김 |

‘밝음=무조건 정답’으로 오해시키지 않는다. 천문대에서 광선이 다른 주소로 도착하면 그 수광기는 반응하되 목표 도착 표시와는 모양이 다르다. P00 소켓, 우표, 배역은 색 없이도 식별된다.

### 방별 차이

| 방 | 지배 재료·모양 | 공간의 첫 초점 | 해결 전→후 |
|---|---|---|---|
| 기록보관소 | 얇은 종이·수직 서랍·먹색 물결 | 뒤집힌 기록대 | 삐뚤어진 표지→정렬된 서랍과 열린 점검창 |
| 침수 온실 | 유리·탁한 초록·둥근 수위선 | 젖은 뿌리와 큰 계량통 | 침수→배수→열린 꽃, 수위선은 계속 남김 |
| 천문대 | 어두운 남색·흰 별·원형 고리 | 북쪽 홈과 별 격자 | 끊긴 선→목적지에 이른 광선과 교점 |
| 인형극장 | 붉은 종이·가느다란 줄·앞뒤 층 | 어긋난 열쇠 그림자 | 흩어진 조각→중앙 정렬, 인형 앞뒤 변화 |
| 교환국 | 회녹색 금속·크림 봉투·도장 | 수신장과 비어 있는 응답칸 | 중복 종이 적치→처리/수신 도장 분리 |
| 공방 | 흑연·황동·정수 눈금 | 멈춘 중심축 | 제각각인 창→공동 위상, 분리된 전력선 |
| 출구 기관 | 여섯 재료의 작은 모듈 | 잠금핀 세 개와 문틀 | 모듈별 순차 해제→처음 보는 아침빛 |

## 4. 인물·소품·화면 정보

윤서는 팔을 쓸 수 있는 작업복, 접수 도장 주머니, 수첩의 황동 모서리로 알아본다. 방마다 의상을 바꾸지 않는다. 문지기는 얼굴 애니메이션보다 얇은 안내 슬롯과 도장 기계가 정체성이다. 여섯 화자는 현재 NPC가 아니라 각 기록의 필체·테두리·서명으로 구분한다.

물품은 장식용 소품과 다른 굵기의 상호작용 외곽을 갖는다. 필수 단서는 확대면에서 최소한 한눈에 읽을 면적을 보장하고, 환경 화면에서 작은 경우에도 윤곽 표시 기능으로 위치를 찾을 수 있다. 삼각형·원·잎처럼 서로 다른 표식은 밝기 변화 후에도 같은 정체성을 유지한다.

정보의 우선순위는 ①현재 목표 ②조작 가능한 장치 ③현재 실제 상태 ④필요한 원문 ⑤분위기 소품이다. 아직 보지 않은 서명이나 잠금의 답을 HUD 장식으로 먼저 보여 주지 않는다. 장치가 열리지 않았을 때는 ‘미개방’이라고만 표시한다.

### 글자

한글·숫자·방향 기호의 폭과 기준선을 확인한다. 최종 출력에서 본문 약 20~24px, 작은 보조문도 약 18px를 시작 가설로 두고 확대를 제공한다. 실제 플레이 화면에서 검증해 조정한다. 조건 문장은 2~3줄 안에서 끊고, 전체 원문은 수첩에서 다시 읽는다. 알파벳 기획 식별자를 세계 속 암호로 억지 노출하지 않는다.

## 5. 피드백·움직임·음향

입력한 물체가 먼저 움직이고 연결 경로, 수신기, 결과가 순서대로 반응한다. 결과 전파는 짧게 보여 주되 ‘전체 결과 바로 보기’를 제공한다. 되돌림은 역재생 쇼보다 실제 설정 변화가 우선이다. 성공한 모듈은 재방문 때도 확정 상태를 유지한다.

저동작 모드에서는 물결·깜빡임·먼지·카메라 흔들림을 끄고 단계별 상태 교체로 대체한다. 천문대 광선은 연속 점멸 대신 고정 경로를, 극장 인형은 앞/뒤의 두 정지 자세를 제공한다. 전환 도중 메뉴를 열어도 결과가 두 번 반영되지 않는지는 구현 검증 항목이다.

소리는 빗방울, 종이 마찰, 수위 변화, 거울 체결, 종이 인형 줄, 도장, 기어 이의 접촉이 중심이다. 해결음보다 장치 반응을 먼저 들려준다. 모든 필수 정보는 자막과 상태 표식에도 있다. 선택 악보조차 소리 없이 토큰으로 풀 수 있다. 성우 녹음은 기본 범위에 넣지 않는다.

## 6. 대표 게임 순간

| 순간 | 플레이 행동·초점 | 입력 전후의 변화 | 시안의 실패 예 |
|---|---|---|---|
| 수첩 첫 비교 | 도면을 문축 옆에 고정 | 사각 축/홈을 동시에 대조 | 핀창이 손잡이를 가리거나 글자가 더 작아짐 |
| 온실 시험 배수 | 통별 경로 선택 | 통의 양이 수신량으로 나뉘고 합계 유지 | 수면 효과가 눈금을 가림 |
| 천문대의 빛 | 거울 방향 전환 | 실제 경로·도착 주소가 바뀜 | 장식 광선이 목표 광선과 같은 강도 |
| 극장의 열쇠 | 고정 조각부터 시점 조절 | 분리된 세 그림자가 중앙에서 하나가 됨 | 배경에서도 이미 완성 열쇠처럼 보임 |
| 우편의 재전송 | 41 다시 보내기 | 인도장은 그대로, 확인칸만 생김 | 종이 애니메이션이 인도 횟수를 늘린 듯 보임 |
| 출구 세 모듈 | 서로 다른 규칙 결합 | 핀 세 개가 실제로 차례로 올라감 | 성공 글자만 바뀌고 문에는 변화 없음 |

이 순간은 포스터가 아니라 실제 조작 화면으로 확인한다. 후속 구현에서 제목·온실·투영·최종부·엔딩 화면을 캡처해 확인했다. 별도 원화 후보의 선택이나 최종 도트 품질 판정은 아직 하지 않았다.

## 7. 필수 표현과 줄일 수 있는 것

| 필수 | 없으면 손상되는 플레이 효과 | 줄일 수 있는 표현 |
|---|---|---|
| 기호·원문·수치·북쪽 홈·깊이·눈금 | 정답 추론과 위치 판단 | 배경 잡문서 수 |
| 장치의 입력 전후·실패 상태 | 실험 결과 학습 | 중간 부품의 부드러운 애니메이션 |
| 앞/뒤 인형 자세와 레일 투영 | 시점·연동 이해 | 인형별 복잡한 동작 |
| 수신/처리/확인 도장 구분 | 중복 처리 추론 | 봉투의 이동 곡선 |
| 규칙판·수첩·잠금핀·해결 표시 | 진행과 재방문 | 장식용 초상화·환경 먼지 |

소품·인물·문구·도트 자산은 독창적으로 제작한다. 외부 글꼴·음향을 쓰게 되면 해당 출처와 사용 조건을 제작 단계에서 확인한다. 기존 게임의 캐릭터·화면 배치·지도·퍼즐 문구·자산을 복제하지 않는다. 아직 제작하지 않은 이미지의 저작권 확보나 판매 가능한 완성도를 주장하지 않는다.

남은 시각 위험: 4×4 음각에서 중복/빈칸 구분, 어두운 별판의 좌표 가독성, 투영창에서 깊이의 인지, 0부터 세는 위상의 명확성, 한글 확대 시 장치 가림. 모두 실제 화면 확인이 필요하다.

## 8. 도트 그래픽 고도화 v1.1

기존 정체성을 이어가며 방 전체와 캐릭터·소품·장치 패널을 고도화했다. 정수 좌표로 선·면·타원을 그려 원본의 날카로운 픽셀 윤곽을 유지하고, 재질별 명암과 창밖 항구·낮은 빛·접촉 그림자·수면 반사를 추가했다. 조사 표식과 패널은 읽기와 포커스를 유지한 채 황동 모서리와 음각 방향으로 정리했다.

수위·개화·광선·문 잠금과 인형의 앞뒤는 실제 복구 상태를 읽어 표현한다. 색과 분위기 때문에 해결 전에 성공한 것으로 보이지 않게 한다. 비교 기준은 [전후 이미지와 검토](VISUAL_REVIEW.md), 실제 입력·화면의 기준은 [게임 검증](../game/qa/verification.json)이다. 최종 미술 품질이나 독립된 플레이어의 선호를 확정한 판정은 아니다.
