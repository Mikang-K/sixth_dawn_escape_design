# 게임 기획서 — 여섯 번째 새벽: 폐관 기록

기획 버전 v1.0 · 2026-11-03 · 후속 구현: [게임 안내](../game/README.md)와 [현재 검증](../game/qa/verification.json). 아래는 그 구현의 설계 계약이다.

입력: [요구사항](../PRODUCT_BRIEF.md), [원전 바이블](../analysis/SOURCE_BIBLE.md), [선택 콘셉트](../concepts/CONCEPT.md). 적용 단계: `game-world-design`.

## 1. 경험과 플레이 순환

**한 줄 소개:** 폐관한 전시관의 여섯 방에서 서로 다른 장치의 규칙을 복원하고, 그 관계를 출구의 세 장치에 다시 적용하는 도트 그래픽 방탈출.

플레이어는 폐관 문서를 인계받는 접수자 윤서다. 목표는 회랑에서 갈 수 있는 방을 골라 복구하고 실제 출입문을 여는 것이다. `experienceProfile: system-led`, `signature_command: N/A`. 관찰·배열·회전·계량·경로 선택·토글·박자 전진이 주된 행동이다.

```text
회랑에서 방 선택 → 장치와 단서 관찰 → 수첩에 원문/관계 고정
        ↑                                      ↓
   복구 상태 확인 ← 규칙판 획득 ← 실험 결과로 가설 수정
        └────────── 배운 관계를 최종 장치에 적용 ──────────┘
```

수첩은 물품을 복제하거나 시간을 되돌리지 않는다. 발견한 원문, 장치 도해, 자신이 남긴 설정, 규칙판을 다시 보여 준다. 정답은 장치에 직접 적용해야 한다. 원전의 ‘관계만 보존하는 장치’가 조작 대상과 순서를 바꾸며, 실제 복구 결과는 회랑과 출구에 남는다.

| 장르의 기본 기대 | 제공 방식 |
|---|---|
| 공간 진입과 이동 | 방 전체 화면의 출구·장치를 클릭, 회랑의 문으로 이동. 이동 애니메이션은 건너뛰기 가능 |
| 목표 확인 | 현재 장치의 한 문장 목표, 회랑의 열린 방·해결 표시, 최종 잠금핀 세 개 |
| 물품과 관찰 | 물품 선택 후 대상 선택, 원문 자동 복사, 단서 핀과 비교 보기 |
| 막힘 뒤 재방문 | 두 방 병렬 개방, 언제든 회랑 복귀, 이전 장치 설정 유지 |
| 진행 보존 | 자동/수동 저장 계획, 장치별 되돌리기·초기화, 마지막 엔딩 선택 전 저장 |

첫 60초에 어두운 접수대, 닫힌 내부 문, 기호 세 개의 전원 장치를 보여 준다. ‘임시 전원을 복구하자’가 첫 목표다. 긴 세계관 설명보다 소켓 한 곳을 먼저 조작하게 한다.

## 2. 세계 규칙과 진행

### 공간 구조

| 구간 | 열린 공간 | 통과 조건 | 회랑에서 보이는 변화 |
|---|---|---|---|
| 접수 | 접수대 | P00-1·2 | 내부 문 영구 개방 |
| 1단 | 기록보관소 / 침수 온실 | 두 방의 세 번째 문제 모두 완료 | 서랍 정렬, 수위 복구, 2층 두 문 개방 |
| 2단 | 천문대 / 종이 인형극장 | 두 방의 세 번째 문제 모두 완료 | 별등 연결, 무대 개방, 3층 두 문 개방 |
| 3단 | 무인 우편 교환국 / 시계 공방 | 두 방의 세 번째 문제 모두 완료 | 접수 봉투 보관, 중심 시계 검사 완료, 출구 기관실 개방 |
| 최종 | 출구 기관실 | F-1→F-2→F-3 | 잠금핀 하나씩 해제, 실제 문 개방 |
| 종료 | 선택대 / 외부 | 기록 처리 선택 | 선택한 열람 방식과 출처 표기를 회수한 뒤 아침빛 |

같은 단의 두 방은 어느 순서로든 진행한다. 다른 방에서 가져와야 하는 필수 소모품은 없다. 이전 단의 방은 닫히지 않으며 선택 기록은 엔딩 확정 전 언제든 회수한다.

### 지속할 사실과 판정 권한

| 사실·상태 | 발생 조건 | 나중에 읽는 곳 |
|---|---|---|
| 필수 장치별 해결 사실 23개 | 해당 명세의 완료 조건 충족 | 접근 권한, 목표, 장치 외형, 재입장 |
| 규칙판 6개 | 각 방 마지막 장치 완료 | 회랑 표시와 최종 기관 입장 |
| 현재 장치 설정 | 유효한 조작 | 나가기·재입장·저장 복원 |
| 발견한 단서와 고정한 비교 | 관찰·핀 사용 | 수첩, 힌트 근거, 장치 재확인 |
| 출처 확인 6개 | 선택 문제 각각 완료 | 해당 기록의 실명 표기와 회수 문구 |
| 마지막 처리 선택 1개 | 보존/반환 중 확정 | 해당 전시 상태와 엔딩만 재생 |

무작위 정답·랜덤 시드·실시간 타이머는 없다. 조작 상태와 문서의 규칙이 결과를 확정하고, 그림·음향은 그 판정을 표현한다. 애니메이션 중복 재생이 해결 횟수를 늘리지 않는다.

단서를 수첩에 등록했는지는 보조 정보다. 이미 알아낸 답을 정확히 적용하면 통과한다. ‘올바른 오브젝트를 먼저 관찰하지 않았다’는 숨은 실패 조건은 두지 않는다. 단, 아직 열리지 않은 장치는 진행 구조에 따라 접근할 수 없다.

문자·방향·좌표·박자는 확대면마다 범례를 보인다. 물의 눈금, 이동 박자, 우표 운임은 서로 다른 단위로 표시한다. 박자는 0부터 시작하며 다이얼 범위와 순환 끝을 적는다.

## 3. 결정과 레벨 리듬

| 공간 | 핵심 사고 | 필수 퍼즐과 정답 상태 | 최종부에서의 재사용 |
|---|---|---|---|
| 접수대 | 표식 대조·복수 조건 | P00-1 C/T/S, P00-2 손잡이 H | 관찰·비교 조작의 기반 |
| 기록보관소 | 사건 순서·음각·역복구 | R1-1 DABC / R1-2 90도 / R1-3 CBAD | F-3의 실제 처리 역순 |
| 침수 온실 | 합·보존·허용 시기 | R2-1 2/3/5 / R2-2 동서동서 / R2-3 박자5 | F-1의 분배와 열리는 때 |
| 천문대 | 평행 이동·반사·교점 | R3-1 (3,4) / R3-2 역빗금·역빗금·빗금 / R3-3 (4,3) | F-2의 다른 광선 배치 |
| 극장 | 배치 논리·투영·연동 | R4-1 늑새물사 / R4-2 2/4/6 / R4-3 A/B/C 홀수 | F-2의 다른 투영 배치 |
| 교환국 | 원형 대응·중복·전 경로 비교 | R5-1 서남동북 / R5-2 재41·확41·새42·확42 / R5-3 SACT | F-3의 중복 제외 |
| 공방 | 비율·공동 위상·제약 전파 | R6-1 반시계1 / R6-2 29 / R6-3 B/C/F 켜기 | F-1의 위상 판정 |
| 출구 | 기존 관계의 재조합 | F-1 LRLM / F-2 새 반사·3/6/9 / F-3 SRDK·D제외·KRS | 학습으로 실제 출구 해제 |

각 방은 첫 문제에서 대상을 읽는 법, 두 번째에서 그 방의 중심 규칙, 세 번째에서 상태 변화와 규칙판을 경험한다. 모든 문제를 같은 연출 길이·동작 수에 맞추지 않는다. 공방의 첫 기어 문제는 뒤의 두 복합 문제 사이를 잇는 짧은 정리 구간이다.

권한의 구분: 플레이어는 열린 방의 선택, 가설과 설정, 재시도, 힌트, 선택 기록, 마지막 처리 방식을 결정한다. 단일 정답 퍼즐은 이 프로젝트에서 허용한다. 모든 장치에 전략적 다중 해법이 있는 것처럼 약속하지 않는다. 장치는 실제 입력을 읽어 성공·실패를 확정한다.

정답 상태가 하나여도 동치 조작은 허용한다. 극장 줄의 실행 순서, 우표의 물리적 배치 순서, 기어의 두 중간 순서, 같은 위상으로 여러 바퀴를 도는 입력을 임의로 오답 취급하지 않는다. 세부 범위는 [퍼즐 카드 목록](../README.md#퍼즐-상세)을 따른다.

## 4. 피드백·실패·되돌림

### 조작과 접근성

- 기본: 클릭으로 관찰, 물품 선택→대상 선택, 확대면 닫기, 핀 비교, 되돌림. 드래그만 가능한 필수 동작은 없다.
- 키보드: Tab/방향키로 대상 이동, Enter로 선택·실행, Esc로 한 단계 뒤로, 각 토글·레일·다이얼에 키보드 대체 조작. 포커스를 확대면 안에서 유지한다.
- 간단한 범례를 확인하면 상호작용 지점의 윤곽을 표시하는 기능을 처음부터 제공한다. 중요 단서는 다른 물건과 같은 크기로 숨어 있지 않는다.
- 숫자와 원문은 확대 가능. 장치 조작창·수첩·힌트 창을 겹쳐 중요한 조작을 가리지 않게 한다.
- 색과 함께 무늬·기호·글자 사용. 모든 기능 음향에는 그림/텍스트 대체. 주기는 수동 전진, 리듬은 토큰 배열이므로 청력·반응 속도가 필수가 아니다.

### 결과 피드백

| 입력 결과 | 보여 줄 것 | 다음에 바꿀 수 있는 것 |
|---|---|---|
| 아직 조작 불가 | 부족한 전제와 실제 잠금 위치 | 앞 장치 해결 또는 열린 다른 방 방문 |
| 유효한 실험, 답 불일치 | 실제 수치/위치와 어긋난 관계 | 해당 설정만 수정 |
| 잘못된 작업 순서 | 거부한 이유와 현재 상태 유지 | 다음 작업 선택 |
| 일부 조건 충족 | 충족한 조건과 남은 조건 분리 | 나머지 한 관계를 수정 |
| 성공 확정 | 실제 부품 움직임, 소리 대체 표시, 목표 갱신 | 다음 장치·회랑·선택 기록 |

피드백 문장은 관찰된 상태만 말한다. ‘거의 정답’ 같은 추상 칭찬이나 임의의 정답 거리 점수는 주지 않는다. 최종부는 세 조건을 한 번에 채점하지 않고 모듈 단위로 고정한다.

### 되돌림과 저장

되돌림은 현재 미해결 장치의 마지막 유효 설정 변경을 취소한다. 초기화는 **현재 장치의 시험 상태**만 원래대로 돌린다. 성공해 열린 문, 수첩, 선택 출처, 다른 장치 해결 사실을 지우지 않는다. 해결 장치는 연습 재생으로 볼 수 있으며 연습 종료가 전역 진행을 바꾸지 않는다.

물·씨앗·꽃가루·우표·봉투는 실패로 영구 소모되지 않는다. 필수 도구는 정해진 보관 위치에 남거나 장치에 장착된 상태로 유지된다. 잘못된 대상으로 물품을 사용하면 물품은 원래 위치로 돌아온다.

저장은 장치 해결 직후, 방 이동 시, 최종 선택대 직전에 수행하고 수동 저장을 별도로 제공한다. 불러온 직후 확대면의 실제 설정과 수첩 기록이 일치해야 한다. 후속 구현의 자동·수동 복원 경로와 확인 범위는 게임 검증 JSON에 기록했다.

### 힌트

각 카드의 1단계는 관찰 위치, 2단계는 관계, 3단계는 직접 해답이다. 자동 팝업으로 강제하지 않으며 현재 장치에만 적용한다. 사용량 때문에 엔딩·출처·탈출 자격을 바꾸지 않는다. 장치를 나갔다 들어와도 열어 본 단계는 남긴다. 정답을 보지 않은 단서는 힌트1에서 위치를 먼저 안내한다.

## 5. 서사 첨부와 정보 경계

### 장면의 뼈대

| 장면 | 윤서가 하는 일 | 새로 확인하는 사실 | 다음 장면의 응답 |
|---|---|---|---|
| 접수대 | 수리와 내부 문 개방 | 자신이 폐관 인계 담당임 | 문지기가 미완료 작업 두 곳을 표시 |
| 첫 두 방 | 기록의 순서와 물의 조건 복구 | 보관 상태가 실제 작동을 보장하지 않음 | 회랑의 실제 수위·표지판 수정 |
| 가운데 두 방 | 좌표·시선·투영 대조 | 보이는 하나의 결과가 여러 원인에서 올 수 있음 | 시선 표식·무대 모형 복구 |
| 교환국 | 수신 확인과 접수증 대조 | 윤서가 이전 접수자임, 중복은 인도가 아님 | 원본 접수 봉투가 출구 슬롯으로 이동 |
| 공방 | 방향·주기·전력 정렬 | 빠르기보다 조건의 합치가 잠금을 열음 | 기관실 접근 허용 |
| 최종 기관 | 관계를 새 장치에 적용 | ‘보관 완료’와 ‘반환 가능 확인’의 혼동을 해소 | 실제 문 개방, 처리 선택 공개 |
| 선택대 | 열람 방식 선택 | 두 방식 모두 사본을 유지함 | 선택한 방식만 세계에 반영 |

문지기의 문장 예: 시작 ‘접수는 남아 있습니다. 완료 기록이 없습니다.’ 온실 뒤 ‘수위 확인. 보관 상태를 갱신합니다.’ 마지막 ‘인도와 보관을 같은 항목으로 읽었습니다. 처리 방식을 지정해 주십시오.’ 숨은 규칙이나 아직 보지 않은 기록 내용을 먼저 말하지 않는다.

### 누가 무엇을 아는가

| 사실 | 세계의 사실 | 플레이어가 아는 시점 | 알려 주지 않는 내용 |
|---|---|---|---|
| 윤서의 예전 접수 서명 | 접수증에 이미 존재 | 교환국 R5-1에서 원문 확인 | 모든 기록의 작성자가 윤서라는 추정 |
| 41번의 중복 수신 | R5-2 초기에 이미 일어남 | 초기 기록과 인도장에 명시 | 숨겨진 무작위 추가 손실 |
| 관리 기록의 출처 | 각 원본에 직접 표기가 있음 | 해당 선택 문제 완료 뒤 | 미해결 출처의 실명 확정 |
| 기록 주체의 현재 | 이 기록에는 없음 | 끝까지 판정 불가 | 생사·위치를 결말에서 임의 확정 |

주요 분기는 공통 탈출 뒤의 선택대에서만 갈린다. 공유 동선은 합류하되 선택한 처리 방식과 회수한 출처를 마지막에 구체적으로 읽는다. 공용 보존은 전시를 남기고, 반환은 개인함으로 이동시킨다. 힌트나 속도를 숨은 도덕 점수로 바꾸지 않는다. 별도 장편 인물 루트는 만들지 않는다.

## 6. 언어·문화·미술 인계

한국어가 기본이다. 긴 일기는 필수 정보 한 문장과 배경 문장으로 나누며, 판정에 필요한 제약은 다시 보는 짧은 원문으로 남긴다. ‘바로 다음’, ‘정확히 하나’, ‘하나 이상’, ‘모두 사용’처럼 조건의 강도를 구분한다. ‘한 칸’이 대각선을 뜻하는 예외는 없다.

세계는 가상의 아날로그 항구도시다. 외국어를 알아야 하는 암호, 실재 천문 별자리, 달력 요일 계산, 악보 지식, 통신 프로토콜 용어는 필수 관문으로 쓰지 않는다. 눈에 보이는 단서가 디자인 문서의 규칙과 같은 의미를 가져야 한다.

미술은 작은 단서를 크게 읽을 수 있는 도트 확대면, 방마다 구분되는 지배색·윤곽·재료, 성공 전후의 실제 상태 변화가 필요하다. 세부 방향은 [아트 디렉션](ART_DIRECTION.md)으로 넘긴다. 엔진·저장 형식·구현 구조는 이 기획서에서 정하지 않는다.

## 7. 실행 가능한 첫 절단의 계약

**최대 위험:** 물의 분배와 열린 박자를 직접 조작해 이해하고, 배경이 달라져도 같은 관계를 적용할 수 있는가.

검증 형태는 실제 조작이 가능한 2D 회색상자다. 텍스트 문제집은 합계·논리를 점검할 수 있지만 클릭 대상, 수위, 박자, 원근의 가독성을 증명하지 못한다.

| 경로·초기 상태 | 전제와 행동 | 기대 결과·피드백 |
|---|---|---|
| 접수대, 전원 꺼짐 | C/T/S 맞춤, H 장착 | 내부 문 열림, 수첩 원문과 핀 동작 |
| 회랑, 온실 미해결 | 온실 진입 | 첫 장치와 나갈 곳이 바로 보임 |
| R2-1, 질량 미지정 | 2/3/5 지정 | 세 저울 모두 일치, 계량통 개방 |
| R2-2, 수량0/0 | 동서동서 설정·시험 | 동4/서6, 침전 경로 일치, 개화창 접근 |
| R2-3, 박자0 | 박자5로 이동·수분 | 개화, 규칙판 획득, 회랑 수위 변화 |
| 회랑 귀환 | 나가기·재입장·저장 복원 | 해결 표시와 설정 유지, 수첩 정보 복기 가능 |
| 별도 전이 검증 상태 | 다른 다섯 방을 완료한 고정 상태로 F-1을 열고 LRLM 계획 | 새 실린더에서 총량·박자 관계를 적용해 핀 해제 |

전이 검증의 다른 다섯 방 완료는 **검증용 고정 초기 상태**이며 실제로 다섯 방을 플레이했다는 증거가 아니다. 정상 진행의 관문과 구분해 실행한다. 첫 절단의 정상 경로는 온실 해결 뒤 회랑 귀환까지다.

반례는 R2-2의 4통 동쪽, R2-3의 박자4, F-1의 LRLR, 재입장 중 미해결 설정 유지, 음소거·저동작·키보드 경로다. 모두 관찰하고 수정할 수 있어야 한다.

## 8. 검증 범위와 수정 조건

기획의 [수리 검증](../validation/VALIDATION_REPORT.md)과 후속 게임의 [실제 조작 검증](../game/qa/verification.json)은 별개 근거다. 실제 재미·초심자의 직관성·난이도·플레이타임은 미검증이다.

첫 회색상자에서는 초심자5명과 장르 경험자2명을 관찰하는 소규모 탐색 테스트를 계획한다. 통계적 성공률을 주장하는 표본이 아니다. 관찰 지점은 첫 클릭, 단서 복기, 오답 후 수정, 방 전환, 새 장치 전이와 입력 편의다.

동일한 막힘이 초심자 두 명 이상에게서 나오면 단서 위치·범례·피드백 중 원인을 분리해 수정한다. 직접 해답을 읽어야만 전이가 되면 최종 규칙을 늘리지 말고 앞방의 학습·비교 수첩을 먼저 고친다. 한 방의 글자량 때문에 계속 읽기를 포기하면 문서 수를 늘리지 말고 핵심 문장과 배치를 줄인다.

광선·투영은 별도 천문대/극장 회색상자로 검증한다. 첫 온실 절단이 통과했다고 모든 공간 퍼즐의 품질이 증명된 것으로 처리하지 않는다. 세부 관찰표와 제작 순서는 [플레이테스트 계획](../production/PLAYTEST_PLAN.md)에 둔다.
