# SOURCE_BIBLE — 원전에서 가져온 설계 근거

원전: [독창적 설정 원전](../source/ORIGINAL_SETTING.md). 이번 요청에 따라 창작한 내부 원전이며 기존 소설의 분석 결과가 아니다. 퍼즐의 구체적 숫자·배치는 후속 기획 발명이다.

## 1. 중심 긴장과 게임 가능한 사실

| 근거 | 원전 사실 | 게임에서 검증할 행동 |
|---|---|---|
| S01 | 서로 다른 교육용 장치가 출구에 연결됨 | 독립된 방의 규칙을 출구의 새 배치에 적용 |
| S02 | 기록 순서와 사건 순서가 다를 수 있음 | 사건을 정렬한 뒤 복구 순서는 거꾸로 실행 |
| S02 | 기록이 보존하는 관계는 여섯 종류로 제한 | 순서·양·좌표·투영·번호·주기 이외의 만능 능력 금지 |
| S03 | 전사 수첩은 관찰을 복기하고 규칙판을 보관 | 원문을 핀으로 붙이고 실험 전후를 나란히 확인 |
| S04 | 같은 결과도 관점·양·시간에 따라 달라짐 | 화면의 모양과 원인을 구분해서 장치를 조절 |
| S05 | 문지기는 보관 완료와 수신 확인을 혼동 | 중복과 실제 처리 기록을 구분해서 잠금 해제 |
| S06 | 탈출 성공 이후 두 처리 방식이 존재 | 후속 열람 권한의 차이를 알고 직접 선택 |
| S07 | 실패는 장치 안에서 복구 가능 | 되돌리기·장치 초기화·귀환을 모든 필수 관문에서 제공 |

## 2. 공간, 행동, 저항

| 공간 | 원전 앵커 | 반복 가능한 행동 | 실행 저항 | 가시적 변화 |
|---|---|---|---|---|
| 기록보관소 | 정정문·접수 서명 | 배열, 겹치기, 역순 조작 | 기록물 표면과 사건 원인의 차이 | 원본 무늬, 복구된 손잡이 |
| 침수 온실 | 관찰표·계량기 | 계량, 분배, 박자 전진 | 총량과 개별 허용량·시기 | 수위와 개화 창 |
| 야간 천문대 | 관측 노트 | 대조, 반사, 교점 선택 | 방향·좌표·시점의 혼동 | 연결된 별등과 관측점 |
| 종이 인형극장 | 앞뒤 장치도 | 배역 배치, 시점 이동, 줄 당기기 | 가려짐·연동된 반응 | 열쇠 실루엣과 커튼콜 |
| 무인 우편 교환국 | 전달 규약 | 분류, 재전송, 경로 선택 | 중복·응답 누락·운송 길이 | 수신장·인도 확인 |
| 멈춘 시계 공방 | 점검표 | 비율 추론, 위상 조정, 회로 조합 | 방향·주기·전력 한도 | 맞물린 바늘과 동력 분리 |

## 3. 인물의 의지와 정보 경계

- 윤서: 밖으로 나가기 위해 절차를 이어받는다. 서명한 접수자라는 사실은 우편 교환국에서 확인하며, 모든 기록의 작성자로 둔갑시키지 않는다.
- 문지기: 기록이 사라질까 걱정해 계속 보관한다. 해결 상태를 읽어 안내한다. 해결 이전에 규칙이나 결말을 알아서 대신 수행하지 않는다.
- 여섯 기록 주체: 실제 대화 NPC가 아니라 기록 속 화자. 말하지 않은 의도나 현재 위치를 임의로 추론해 확정하지 않는다.

## 4. 시각·청각 앵커

황동 모서리가 달린 수첩, 서로 다른 여섯 방에 반복되는 얇은 동선, 탁한 남색 새벽, 조작 뒤에만 켜지는 호박색 표시, 창유리에 맺힌 비, 마른 종이의 미세한 떨림. 기록보관소의 뒤집힌 날짜, 온실 수위선, 천문대 방향 표식, 극장 앞뒤의 분리, 우편의 수신 도장, 공방의 분할 눈금을 기능적 단서로 사용한다.

## 5. 각색·발명 경계

| 유지할 사실 | 허용하는 기획 발명 | 금지하는 임시 편의 |
|---|---|---|
| 수첩은 관찰 보조 도구 | 핀, 비교 보기, 단계별 힌트 | 임의의 시간 이동·물품 복제 |
| 교육용 기계의 제한된 동작 | 퍼즐 수치, 스냅 격자, 장치 내부 규칙 | 실제 광학·물리 법칙인 척 설명하는 가짜 법칙 |
| 기록의 소유와 수신 확인이 갈등 | 엔딩별 보관 위치와 전시 변화 | 기록을 사람의 생명과 동일시한 숨은 벌칙 |
| 여섯 방의 관계가 출구에 재사용 | 최종 모듈의 새로운 수치·배치 | 예고 없는 일곱 번째 필수 규칙 |
| 실패와 복기는 허용 | 장치별 되돌림과 초기화 | 필수 소모품 소실·재입장 봉쇄 |

원전의 폐관 절차를 그대로 읽는 것은 게임 진전이 아니다. 각 방에서 상태를 바꾸고, 마지막의 다른 장치에도 규칙을 적용해야 한다.
