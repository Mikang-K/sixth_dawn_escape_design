# 여섯 번째 새벽: 폐관 기록 — 플레이 안내

폐관한 전시관의 여섯 방을 복구하는 1인용 도트 방탈출입니다. 필수23개·선택6개 퍼즐과 두 가지 기록 처리 결말을 실제로 플레이할 수 있습니다. 별도의 계정이나 API 키는 필요하지 않습니다.

현재 버전 **1.1**에서는 도트 그래픽을 고도화했습니다. 캐릭터, 항구의 창밖 풍경, 목재·황동·유리·물·천의 표현, 조명과 장치 패널을 새로 다듬었습니다. **[변경 전·후 비교 갤러리](qa/art-review.html)** · **[미술 검토 기록](../design/VISUAL_REVIEW.md)**.

## 실행

현재 개발 서버가 실행 중이면 **[게임 열기](http://127.0.0.1:4176)** 를 누르세요.

서버가 꺼져 있으면 이 폴더의 **[START_GAME.cmd](START_GAME.cmd)** 를 실행한 뒤 브라우저에서 같은 주소를 여세요. Node.js 22 이상이 필요하며 이번 환경에서는 24.18.1로 실행했습니다. 게임 실행에는 `npm install`이 필요 없습니다.

직접 시작하는 경우 이 폴더에서 실행합니다.

```powershell
node server.mjs
```

서버 창을 열어 둔 채 플레이합니다. 종료는 서버 창에서 `Ctrl+C`. `index.html`을 파일로 바로 여는 방식 대신 위의 로컬 주소를 사용하세요. 기본 주소는 이 컴퓨터에서만 접속하도록 바인딩됩니다.

## 처음 할 일

제목 화면에서 ‘새 기록 시작’을 누릅니다. 접수대의 임시 전원을 복구하고 손잡이를 장착하면 회랑이 열립니다. 같은 층의 두 방은 원하는 순서로 방문할 수 있습니다. 각 방을 모두 복구하면 다음 두 방이 열립니다.

- 공간의 `＋` 표식이나 오른쪽 작업 목록을 눌러 장치를 조사합니다.
- 현장 단서를 펼쳐 규칙을 읽고 장치를 조작한 뒤 ‘시험·검사’를 누릅니다.
- 틀리면 어떤 조건이 어긋났는지 결과를 확인합니다. 필수 물품은 사라지지 않습니다.
- ‘되돌림’은 마지막 설정 한 번, ‘초기화’는 현재 장치만 되돌립니다. 이미 복구한 문과 규칙판은 유지됩니다.
- 열린 다른 방으로 이동했다 돌아와도 설정은 남습니다.

## 수첩과 힌트

단서를 읽으면 수첩에 남습니다. ‘수첩에 핀 고정’으로 최대3개의 원문을 장치 옆에서 비교할 수 있습니다. 규칙판은 각 방의 마지막 장치를 해결하면 얻으며 수첩에서 다시 봅니다.

힌트는 관찰 위치 → 관계 → 직접 해답의3단계입니다. 직접 요청할 때만 나타나고, 사용했다고 결말이 달라지지 않습니다. 선택 기록6개도 탈출에 필수는 아닙니다. 이들은 마지막 기록에 작성자의 출처를 더합니다.

## 저장과 다시 시작

설정 변경·방 이동·해결은 자동 저장됩니다. 메뉴의 ‘기록 저장’은 별도의 수동 저장 한 칸을 남깁니다. 설정의 ‘수동 저장 불러오기’로 돌아갈 수 있습니다.

제목 화면의 ‘이어서’는 자동 저장에서 재개합니다. 마지막 기록 처리 직전의 선택대는 별도로 보관하며, 엔딩의 ‘선택대 다시 보기’로 돌아갑니다. ‘새 기록’은 확인한 뒤 현재 게임의 자동·수동·마지막 선택 기록을 지우고 접수대부터 시작합니다.

저장은 브라우저와 주소에 묶입니다. 같은 브라우저의 같은 포트로 돌아오세요. 시크릿 창 종료·사이트 데이터 삭제·다른 주소 사용은 기존 기록을 불러오지 못하게 할 수 있습니다. 저장할 수 없을 때는 게임에 오류 안내가 표시되고 현재 실행 중인 진행은 유지됩니다. 되돌림의 세부 작업 이력은 새로고침 후 다시 쌓이며, 현재 장치 설정·해결·핀·힌트는 복원됩니다.

## 키보드와 화면

`Tab`·`Shift+Tab`으로 조작 대상을 바꾸고 `Enter`·`Space`로 실행합니다. 숫자 입력은 위·아래 화살표, 선택 입력은 방향키를 쓸 수 있습니다. `Esc`는 가장 위의 조사·수첩·설정 창을 닫습니다. 드래그만 가능한 필수 조작은 없습니다.

설정에서 글자 확대, 움직임 줄이기, 조사 위치 윤곽, 장치 소리를 바꿀 수 있습니다. 박자는 수동 전진이며 리듬 문제도 기호로 풉니다. 소리를 켜지 않아도 진행할 수 있습니다. PC 가로1280×720 이상을 우선으로 구현했습니다. 긴 장치나 결말 화면은 스크롤해서 봅니다.

## 문제가 생기면

- 접속이 안 됨: 서버 창이 살아 있는지 확인하고 `node server.mjs`를 실행합니다.
- 주소가 이미 사용 중이라는 오류: 기존 서버가 실행 중이면 같은 주소를 엽니다. 다른 프로그램이 사용 중이면 `PORT` 환경변수로 포트를 지정할 수 있지만 저장도 새 주소로 나뉩니다.
- 입력 숫자가 되돌아옴: 장치의 허용 범위 밖 숫자·빈 값은 저장하지 않습니다.
- 기록이 사라진 것 같음: 같은 브라우저·주소인지, 시크릿 모드인지 확인합니다.
- 회랑의 다음 문이 안 열림: 같은 층의 두 방 모두에서 마지막 장치를 복구해야 합니다. 선택 출처는 필요하지 않습니다.

## 구현과 검증 범위

이번 버전은 전체 퍼즐을 연결하고 도트 미술을 개선한 **플레이 가능한 후보**입니다. 방 배경은 직접 그린 Canvas 도트이고, 장치는 접근 가능한 HTML 조작부와 실제 계산에 따른 도형으로 표현합니다. 거울 광선·계량 분배·깊이별 투영·시계 위상은 설정과 함께 바뀝니다. 상용 출시용 최종 미술 검수·환경 음악·네이티브 실행 파일은 포함하지 않습니다.

현재 검증 사실의 기준은 **[브라우저 검증 JSON](qa/verification.json)** 과 연결된 입력·화면 증거입니다. 알고 있는 풀이로 확인한 자동 검증이며, 초심자의 발견 가능성·주관적 재미·실제 플레이 시간은 확인하지 않았습니다. 정답이 공개되는 기획서는 플레이 전 읽지 않아도 됩니다.
